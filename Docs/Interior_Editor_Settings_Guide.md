# 인테리어 편집 툴(ArchViz) 최적화 세팅 변경 내역

## 프로젝트 렌더링 세팅 (Project Settings -> Rendering)

### 자동 노출 (Auto Exposure / Eye Adaptation)
* **이유**: 어두운 구석이나 밝은 창가를 바라볼 때 화면 전체의 밝기가 계속 변하게 됩니다. 인테리어 작업에서는 가구나 벽지의 정확한 색감과 조명 세팅을 일관되게 확인해야 하므로 자동 노출이 켜져 있으면 굉장히 방해됩니다.
* **설정 위치**: `Project Settings` -> `Rendering` -> `Default Settings` -> **Auto Exposure 체크 해제** (또는 포스트 프로세스 볼륨에서 Min/Max Brightness를 1.0으로 동일하게 고정)

### 블룸 (Bloom) 최소화
* **이유**: 현재 켜져 있는 상태입니다. 빛이 번지는 효과가 리얼리티를 살려주긴 하지만, 편집 툴 자체의 UI나 밝은 오브젝트 주변이 지나치게 번져 보여 정밀한 배치를 방해할 수 있습니다. 완전히 끄거나 수치를 낮추는 것을 권장합니다.

### 안티 에일리어싱 (Anti-Aliasing) 방식 변경
* **이유**: TSR이나 TAA는 카메라를 움직일 때 잔상(고스팅 현상)이 발생할 수 있습니다. 편집 툴에서는 즉각적이고 선명한 화면이 중요하므로, 잔상이 거슬린다면 MSAA나 FXAA로 낮추거나 끄는 것도 고려해볼 수 있습니다. (다만 퀄리티가 떨어져 보일 수 있으니 툴의 목적에 따라 선택)
